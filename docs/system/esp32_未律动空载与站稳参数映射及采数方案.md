# ESP32 未律动阶段：空载与站稳参数映射及采数方案

状态：施工前设计稿；本稿不修改固件参数，不代表参数已通过真机验证。

目的：把“体重版空载判断 → 距离版空载判断 → 体重版站稳判断 → 距离版站稳判断”按固定顺序写清楚，并列出距离参数定值前必须采集的数据。

本文描述的是未律动阶段的有人/空载与站稳判断，不覆盖开始律动后的正常、离台、摔倒判断，也不改变 BLE、SW APP 或 Demo APP 合同。

## 1. 体重版空载计算与判断逻辑

### 1.1 计算

令 D 为 ESP32 统一后的距离，D₀ 为校准模型保存的 0 kg 参考距离：

    x = D − D₀
    W_raw = a·x² + b·x + c
    W = max(0, W_raw)

W 是 ESP32 根据校准模型计算出的体重。正式模型要求常数项 c 接近 0，使模型经过 0 kg 定点；距离无效、模型不存在或计算结果非有限数时，体重无效，不能把无效体重冒充为 0 kg。

模型系数的距离单位必须与 D、D₀ 一致。固件内部距离单位为毫米除以 100；换算参数时必须先统一单位，不能把内部单位数直接当成毫米。

### 1.2 判断

体重版在场判断使用当前换算体重 W：

    W ≥ W_enter  → 有人
    W ≤ W_exit   → 空载 / 无人
    W_exit < W < W_enter → 保持此前状态

这是一组带回差的门槛。刚启动时状态默认为无人，因此读数落在回差区间时仍保持无人；已经判为有人时，落在回差区间则保持有人。

当前源代码默认值是 W_enter = 5 kg、W_exit = 3 kg，进入和退出确认次数均为 1。它们是代码现值，不是本稿建议值，也没有在本稿中声称已由现场实验确认。体重版在场判断收到无效测量时还有单独的无效样本退出处理，不把 NaN 当成 0 kg。

源代码：[体重换算公式](../../src/modules/laser/CalibrationRuntime.cpp#L18)、[LaserModule::updatePresenceState](../../src/modules/laser/LaserModule.cpp#L957)、[PresenceContractEvaluator](../../src/modules/laser/PresenceContractEvaluator.cpp#L12)、[体重门槛配置](../../src/config/LaserPhase2Config.h#L12)。

当前 J100-485 / CYD3S1612-IIC 在场判断由距离链拥有；这里的体重版逻辑是要对照和映射的参考算法，不应误称为当前 J100 的空载主判断。

## 2. 距离版空载计算与判断逻辑

### 2.1 计算

令 D₀ 为本台设备通过 0 kg 校准点确认并保存的空载距离，D 为传感器统一后的物理距离：

    ΔD = |D − D₀|

距离版运行时只计算距离偏移，不把距离再换算为体重来作状态判断。当前代码使用绝对偏移；采数时还需确认受载方向是否始终一致。如果方向有明确物理含义，应验证采用有符号偏移是否比绝对值更安全。

若只为离线推算体重门槛对应的距离，可使用已知校准曲线求根：

    D_enter = 与实际受载方向一致的 f⁻¹(W_enter)
    D_exit  = 与实际受载方向一致的 f⁻¹(W_exit)
    T_enter_D = |D_enter − D₀|
    T_exit_D  = |D_exit − D₀|

二次模型可能有多个数学根，只能选实际传感器工作区间内、与实测受载方向一致的根。该反算用于制定距离参数；距离状态运行时不应依赖 W 或校准模型。若传感器分辨率不足以区分空载与进入门槛，应记录为测量能力不足，不能靠降低阈值掩盖。

### 2.2 判断

距离版保留体重版的回差结构：

    ΔD ≥ T_enter_D → 有人
    ΔD ≤ T_exit_D  → 空载 / 无人
    T_exit_D < ΔD < T_enter_D → 保持此前状态

其中 T_enter_D、T_exit_D 的单位为毫米，并要求 T_enter_D > T_exit_D。连续确认次数记作 C_enter_D、C_exit_D；通过数据评估后确定，不能预先把当前距离代码里的 2 次确认说成已验证结果。

空载基准 D₀ 是本台测量机构的物理 0 kg 参考点，不是按传感器型号随意设定的默认距离。传感器的精度和分辨率可能影响 T_enter_D、T_exit_D 的可用值；是否需要按后端配置不同门槛，须由 J100 与 CYD 的重复性数据决定。

### 2.3 当前代码与目标的差异

当前 DistanceStateChain 默认值为：

| 当前代码字段 | 当前内部单位值 | 换成物理距离 | 本稿处理 |
|---|---:|---:|---|
| emptyEnterDelta | 0.03 | 3 mm | 只记录为现值，不认定为正确值 |
| emptyExitDelta | 0.01 | 1 mm | 只记录为现值，不认定为正确值 |
| confirmSamples | 2 | 2 个样本 | 作为待评估现值 |

内部距离单位为 mm / 100，换算定义见 [GlobalConfig.h](../../src/config/GlobalConfig.h#L82)。距离链没有显式空载参考时，目前会把第一次有效距离临时当作空载参考；正式验证必须记录该情况，并确保测量开始前已设置正确 D₀，不能把“第一次读数”当成已确认的 0 kg 校准点。[当前距离更新实现](../../src/modules/laser/DistanceStateChain.cpp#L67)

## 3. 体重版站稳计算与判断逻辑

### 3.1 进入站稳候选

站稳候选只在设备未律动、已判断有人、体重有效且体重超过 W_enter 时开始。对当前代码参考值而言，W_enter = 5 kg；这是进入评估的最低载荷门槛，不代表此时已经站稳。

体重版站稳不会直接对原始距离窗口计算体重波动。它先平滑距离，再用校准模型计算平滑体重：

    D_f(n) = D_f(n−1) + α·(D(n) − D_f(n−1))
    W_f(n) = f(D_f(n))

当前 α = 0.18。站稳窗口使用 W_f。该平滑及调用位置见 [updateStableSignalFilter](../../src/modules/laser/LaserModule.cpp#L731) 与 [updateStableState 调用点](../../src/modules/laser/LaserModule.cpp#L2048)。

### 3.2 窗口计算

取最近 N 个平滑体重样本 W₁ … Wₙ，当前代码 N = 10：

    μ_W = (Σ Wᵢ) / N
    σ_W = sqrt(Σ(Wᵢ − μ_W)² / N)
    R_W = max(Wᵢ) − min(Wᵢ)
    G_W = |mean(后半窗口) − mean(前半窗口)|

N = 10 时，前半窗口是前 5 个样本，后半窗口是后 5 个样本。标准差使用总体形式，分母为 N；漂移是前后半窗均值的差的绝对值。[窗口公式](../../src/modules/laser/LaserStableWindow.cpp#L1)

### 3.3 站稳通过、锁定与清除

以下三项必须同时通过：

    σ_W < T_sigma_W
    R_W < T_range_W
    G_W < T_drift_W

当前代码配置为 T_sigma_W = 0.20 kg、T_range_W = 0.40 kg、T_drift_W = 0.16 kg；连续 K_stable = 2 次评估通过后锁定站稳。[门槛配置](../../src/config/GlobalConfig.h#L120)、[判定与连续确认](../../src/modules/laser/BaselineEvidenceEvaluator.cpp#L19)

锁定体重基线时，当前代码对最近 N 个样本排序，去掉最高、最低各 r 个，再平均剩余样本；现值 r = 1。因此 N = 10 时，基线是中间 8 个样本的平均值。[基线锁定计算](../../src/modules/laser/LaserModule.cpp#L1318)

锁定后，当前代码在同一清除原因连续出现 K_clear = 2 次时清除站稳状态。清除原因包括：W < W_exit、|W − W_baseline| ≥ 0.5 kg、距离相对站稳距离的偏移达到 1.0 个内部距离单位；按当前内部单位换算，这一项是 100 mm。它是当前旧规则，不应未经审计直接搬入新距离版。连续无效站稳样本达到当前配置的 2 次也会清除。[清除条件与计数](../../src/modules/laser/LaserModule.cpp#L1291)

当前 J100 距离版在场判断启用时，体重站稳分支仍会在体重有效时并行运行；这不改变“有人/无人”的距离 owner。[距离在场与体重站稳调用](../../src/modules/laser/LaserModule.cpp#L1996)

旧的 9 样本提前锁定常量目前没有进入站稳通过判定，应以实际执行的 10 样本窗口逻辑为准。

此处记录的是当前代码事实。它们不等于传感器适用性结论，也不自动成为距离版的最终毫米门槛。

## 4. 距离版站稳计算与判断逻辑

### 4.1 计算

沿用同一种滤波形式，但直接以统一后的距离为计算量：

    D_f(n) = D_f(n−1) + α_D·(D(n) − D_f(n−1))

从最近 N_D 个滤波距离计算：

    μ_D = (Σ Dᵢ) / N_D
    σ_D = sqrt(Σ(Dᵢ − μ_D)² / N_D)
    R_D = max(Dᵢ) − min(Dᵢ)
    G_D = |mean(后半窗口) − mean(前半窗口)|

距离版要沿用体重版的“离散度 + 极差 + 前后半窗漂移”结构；不把现有距离链较简单的“极差 + 当前值与窗口最旧值比较”当作等价公式。

### 4.2 判断与基线

距离版在未律动、有人且样本有效时，要求：

    σ_D < T_sigma_D
    R_D < T_range_D
    G_D < T_drift_D

并连续 K_stable_D 次通过后锁定距离站稳基线。T_sigma_D、T_range_D、T_drift_D 的单位为毫米。基线建议沿用体重版的截尾均值形式：排序最近 N_D 个样本，去掉两端各 r_D 个，再平均其余距离样本。以上字母参数都要等数据采集与回放后定值。

体重波动门槛到距离门槛的局部近似换算为：

    f'(D) = 2a·(D − D₀) + b
    T_sigma_D(mm) ≈ 100·T_sigma_W(kg) / |f'(D*)|
    T_range_D(mm) ≈ 100·T_range_W(kg) / |f'(D*)|
    T_drift_D(mm) ≈ 100·T_drift_W(kg) / |f'(D*)|

这里 D、D₀ 使用固件内部 mm/100 单位，f'(D*) 的单位是 kg/内部距离单位，D* 是待评估的代表工作距离。该近似只适用于曲线在目标范围内单调且局部斜率变化不大的情况。若正常使用范围较宽或二次项影响明显，须用实测的配对窗口重新确定距离门槛，不能把同一个斜率套到全量程。

空载/有人状态由第 2 节的 T_enter_D、T_exit_D 及其确认次数控制；站稳基线的清除还需单独确定 T_rearm_D、K_clear_D 和无效样本宽限数 G_invalid_D。若希望它们与体重版 0.5 kg 基线偏移、离台门槛对应，必须分别用校准关系和真机数据映射，不能混作一个“站稳阈值”。

### 4.3 当前距离站稳实现与目标差异

当前 DistanceStateChain 对最近 10 个距离取极差，并比较当前距离与窗口最旧距离的差；使用的稳定范围和漂移默认值各为 0.01 个内部单位，即各 1 mm。当前基线取窗口最大值与最小值的中点，基线偏移达到 0.02 内部单位（2 mm）时会清除，未使用体重版相同的标准差公式、前后半窗均值漂移公式、截尾均值和连续站稳确认。[当前距离稳定逻辑](../../src/modules/laser/DistanceStateChain.cpp#L110)

这些值只用于说明现状；不作为目标参数，也不应在没有采数证据时写入生产默认值。

## 5. 距离参数定值前需要采集的数据

所有数据都应来自 ESP32 实际测量链，时间戳和物理单位明确。J100-485 与 CYD3S1612-IIC 分开标记、分开统计；算法结构相同不代表传感器参数必然相同。

| 数据组 | 需要记录的内容 | 用途 |
|---|---|---|
| 传感器样本 | 后端型号、原始读数、ESP32 转换后的 distance_mm、有效性、序号、设备时间戳、采样间隔 | 确认分辨率、量化步进、丢样及实际采样节奏 |
| 空载重复性 | 已确认 0 kg 且机械状态稳定时的连续距离；重复放空、恢复、重新上电后的距离序列 | 估计 D₀ 周围的均值、标准差、极差、漂移及空载自然波动 |
| 已知载荷映射 | 0 kg、靠近当前体重版 3 kg/5 kg 判定点的已知载荷，以及正常使用载荷范围；每种载荷下同步记录距离与模型计算体重 | 确认距离变化方向；离线求 T_enter_D、T_exit_D 的候选范围；检查模型反算是否单调且有唯一物理分支 |
| 上台/离台过程 | 从空载到加载、从加载到空载的完整时间序列，包括缓慢上台、快速上台、下台和载荷撤除 | 评估进入/退出回差、确认次数、误触发和状态恢复延迟 |
| 站稳过程 | 人站上后从开始承重到保持姿势的完整距离序列；同步记录同一时刻的体重模型输出，供离线对照 | 计算 σ_D、R_D、G_D 的真实分布，并与体重版 σ_W、R_W、G_W 结果逐段比较 |
| 重复与边界情况 | 多次独立上台/下台；不同有效载荷；正常细微晃动、呼吸引起的自然变化；传感器短暂无效和恢复 | 评估稳定误判、迟判、清除与恢复门槛 |
| 校准信息 | D₀、拟合类型、模型系数、模型版本、校准点原始距离和参考重量 | 复核 kg 到 mm 的映射，仅用于离线分析，不让距离判断运行时依赖体重值 |

采集批次数记作 R，单次连续样本数和持续时间记作 M、T；它们先作为数据记录字段，不在没有数据前臆定固定数量。每个样本必须能追溯其所属传感器、测试轮次、已知载荷、机械状态和有效性。

## 6. 参数如何从数据确定

1. 先从校准数据确认受载距离方向，并确认校准曲线在目标范围内是否单调、可逆。对 W*，二次模型候选根为 x = (−b ± sqrt(b² − 4a(c − W*)))/(2a)，再取实际工作区间且方向正确的 D* = D₀ + x；若 a = 0，则 x = (W* − c)/b。若目标范围内有多个可行根或方向反转，不能用单一静态距离门槛映射。
2. 用已知载荷下的距离平台值，求出体重版 W_enter、W_exit 对应的距离偏移候选值；再用上台/下台重复数据验证门槛间留出的回差是否足以避开空载波动。
3. 对同一组站稳数据，分别离线计算体重指标和距离指标。找出能复现体重版有效站稳/未站稳区分、同时符合距离传感器重复性的 T_sigma_D、T_range_D、T_drift_D 候选值。
4. 回放候选参数，比较误判次数、站稳确认时间、下台识别时间及空载恢复情况。分别统计 J100 与 CYD；如果某后端的噪声或量化步进已经大于可接受的判断差异，则记录为硬件/精度限制，不靠随意放宽全部门槛掩盖。
5. 参数通过离线回放后，再确定是否采用共享默认值或后端 profile 值，并进入单独实现与真机验证。未经该流程，距离参数保持符号状态。

公开计量资料支持用重复测量数据描述测量过程的重复性、稳定性和不确定度；它们不替本设备给出毫米阈值。非线性映射应按测量函数及其局部变化率评估，不能假设 1 kg 永远对应固定毫米数。[NIST 测量过程特性](https://www.nist.gov/publications/nistsematech-engineering-statistics-handbook-chapter-2-measurement-process)；[NIST 不确定度传播定律](https://www.nist.gov/pml/nist-technical-note-1297/nist-tn-1297-appendix-law-propagation-uncertainty)。

## 7. 待定参数表

| 参数 | 含义 | 单位 | 定值依据 |
|---|---|---|---|
| D₀ | 本台机构的正式 0 kg 空载距离 | mm | APP 记录的 0 kg 点及 ESP32 持久化模型 |
| s | 受载距离变化方向 | +1 / −1 | 已知载荷数据 |
| T_enter_D | 从空载进入有人判定的距离偏移 | mm | W_enter 对应曲线反算 + 上台重复数据 |
| T_exit_D | 从有人恢复为空载的距离偏移 | mm | W_exit 对应曲线反算 + 下台重复数据 |
| C_enter_D / C_exit_D | 进入/退出连续确认样本数 | 个 | 噪声回放和响应延迟 |
| α_D | 站稳距离滤波系数 | 无量纲 | 距离噪声及响应时间回放 |
| N_D | 站稳窗口样本数 | 个 | 体重版窗口对照和采样频率 |
| T_sigma_D | 距离窗口标准差上限 | mm | 稳态、自然晃动与未稳态数据 |
| T_range_D | 距离窗口极差上限 | mm | 稳态、自然晃动与未稳态数据 |
| T_drift_D | 前后半窗口均值差上限 | mm | 站稳收敛过程数据 |
| K_stable_D | 连续合格窗口数 | 个窗口 | 稳定误判与确认时间回放 |
| r_D | 距离基线截尾数 | 个/每侧 | 与异常点比例和体重版对照 |
| T_rearm_D | 相对距离站稳基线的清除门槛 | mm | 基线偏移及重新站稳数据 |
